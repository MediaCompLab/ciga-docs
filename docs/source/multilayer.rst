Named temporal layers (development checkout)
============================================

``TMultiLayerGraph`` retains named raw TGraphs so that multiple projections can be
computed without losing cancellations. It is a lightweight container, not a new
multilayer centrality model. No new dependency or Python baseline is required.

Keep layers, then project
-------------------------

This complete example constructs positive/negative magnitude layers::

    import pandas as pd
    import ciga as cg

    def layer(weights):
        return cg.TGraph(data=pd.DataFrame({
            'time': [1, 2, 3], 'source': ['A', 'A', 'A'],
            'target': ['B', 'B', 'B'], 'weight': weights,
        }), positions=['time'])

    layers = cg.TMultiLayerGraph(
        {'positive': layer([3, 0, 4]), 'negative': layer([0, 5, 0])},
        time_unit='seconds', clock_id='example-cut',
        metadata={'description': 'synthetic demonstration'})
    total = layers.project({'positive': 1, 'negative': 1})
    net = layers.project({'positive': 1, 'negative': -1})
    strengths = cg.tgraph_degree_centrality(
        net, weighted=True, accumulate=True, w_normalized='max_abs')
    original_positive = layers['positive']  # independent TGraph copy

The raw cumulative net balances are 3, -2 and 2; the total balances are 3, 8 and 12.
The original negative layer remains available even when a projected dyad cancels.
Layer names are labels: a layer called ``negative`` is not automatically negated.
For nonnegative negative-affect magnitudes, use coefficient -1 to form a net graph;
for an already signed layer, its stored signs already enter the sum.

Projection is linear on raw event weights and initial graphs. Normalize the
projected snapshots explicitly afterward. Separately normalizing each layer first
defines a different model; the container never does this silently. The default
projection policy is ``'signed'``, even for all-positive coefficients. Explicit
``weight_policy='positive'`` requires nonnegative resulting event weights and
initial edges; invalid negatives raise instead of being clipped.

Alignment and support
----------------------

Layers must share directedness and identical ordered position columns. Positions
must contain finite numeric coordinates. Observed time points may differ: an absent
event contributes zero, without interpolation. Initial graphs are combined
separately and contribute only to cumulative snapshots, following TGraph's rules.
Duplicate event keys and parallel initial edges are summed; zero event rows retain
node/time support. Signed snapshot topology omits exact zero edges.

``time_unit`` and ``clock_id`` describe a common time axis. The constructor rejects
conflicting declarations in layer metadata, container metadata or its explicit
arguments, and infers matching known declarations. An undeclared clock cannot be
verified: the caller must align units, origins and movie versions before combining.
This container does not resample or synchronize mismatched film cuts.

Only keys in ``coefficients`` select layers. An explicit zero coefficient retains
that layer's observed nodes and time points; omitting the key excludes its support.
This can change the node-count divisor of normalized degree. All coefficients and
computed weights must be finite real numbers; overflow raises an error.

Copies, metadata and persistence
--------------------------------

The constructor and mapping access copy raw layers, annotations and initial graphs.
Changing an input or returned layer does not change the stored layer. ``layer_names``
and ``positions`` return tuples; ``metadata`` returns a copied dictionary. Projection
returns a plain TGraph, carrying its coefficients, source policies/metadata, axis
declarations and normalization order in ``tg.metadata['ciga_projection']``.
This reserved key is generated by CIGA. The record describes raw projection
provenance; it is not a complete log of later arbitrary edits to mutable TGraphs.

``TGraph(metadata=...)`` copies user provenance and places a fresh copy in snapshot
and delta graph attribute ``ciga_metadata``. Filtering and arithmetic nest input
provenance in ``ciga_operation`` instead of falsely labelling the result as an
unchanged input projection. Filtering selects event rows, not initial edges.
Animation node selection retains this provenance; visualization styling is unchanged.

``layers.to_event_table()`` exports copied annotated rows with a ``layer`` column.
Choose another ``layer_column`` if that name already exists. Projected events keep
only position/source/target/weight columns; extra annotations remain in stored layers.
A bare CSV does not preserve initial graphs, policies or all metadata. Use Python
pickle for a complete container round trip, loading trusted files only::

    import pickle
    with open('layers.pkl', 'wb') as stream:
        pickle.dump(layers, stream)
    with open('layers.pkl', 'rb') as stream:
        restored = pickle.load(stream)

New TGraph pickles preserve metadata and reset derived caches; old pickles without
metadata load with an empty dictionary. Existing policy defaults are unchanged.
New TMultiLayerGraph pickles require this development implementation; older CIGA
versions cannot load the new class. The temporal-prefix class name replaces the
earlier development name without a compatibility alias. Pickles created under
that earlier name must be loaded with the preserved earlier source checkout and
their raw layers/initial graphs/metadata re-exported for reconstruction with the
current class. For downgrade, retain/export the individual raw TGraphs, their
metadata and initial graphs rather than just the net projection.

Query analysis weight domains
-----------------------------

The registry uses the same domain rules as the analysis guards::

    table = cg.analysis_capabilities(include_temporal=True)
    path_rule = cg.get_analysis_capability('graph_betweenness_centrality')
    assert path_rule['weight_domain'] == 'positive'
    cpm_rule = cg.get_analysis_capability('graph_community_leiden', objective_function='CPM')
    topology_rule = cg.get_analysis_capability('graph_betweenness_centrality', weighted=False)

``signed`` allows finite positive/negative/zero weights; ``nonnegative`` excludes
negatives; ``positive`` requires strictly positive lengths; ``ignored`` means the
metric uses topology. Records describe the weighted configuration by default;
``default_mode`` separately states the real function's default. The query's
``weighted=False`` describes unweighted execution and does not change an analysis
call. Signed strength always uses weights and has no unweighted mode.

The table covers the listed snapshot metrics and their sequential temporal aliases,
not hypergraph or native temporal reachability algorithms. It is a weight-domain
contract, not a guarantee of installed optional dependencies, valid objectives,
graph connectivity/directedness, backend-version support or solver convergence.
Leiden CPM permits signed input at CIGA's guard; local backend execution has been
tested with python-igraph 1.0.0 only. Missing-weight conventions are reported
explicitly; always supply the intended weights for weighted interpretation.

See :doc:`signed_weights` for domains and signed visualization, or run the
self-contained ``examples/multilayer_projection.py`` to export a synthetic example.
